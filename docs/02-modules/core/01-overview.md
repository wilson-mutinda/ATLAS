# Core Module Overview

## Purpose

The core module provides system-level services required by all Atlas modules.

Its primary responsibility is to expose endpoints that allow developers, admins, deployment platforms, and monitoring 
systems to verify that the applications is running correctly.

## Current Responsibilities

- Health Monitoring

## Future Responsibilities

- Versioning information
- Readiness checks
- Liveness checks
- System diagnostics

## Dependencies

None.

This module is independent and is available before user authentication.
